# 🏡 Southwind | Premium Real Estate by parkres

A professional, high-conversion landing page for **Southwind**, showcasing Modern Asian-inspired living and scenic views in San Pedro, Laguna. This site is designed to connect potential homeowners with their dream property.

## 🚀 Live Demo
[View the Live Landing Page Here](https://parkres.github.io/Southwind/)

---

## ✨ Key Features
* **Property Showcases:** Detailed sections for the *Banyan* and *Walnut* house models.
* **Modern UI:** Clean, professional aesthetic using Earth-tone color palettes.
* **Responsive Design:** Fully optimized for mobile users searching for properties on the go.
* **Proximity Highlights:** Highlighting easy access via MCX and SLEX to Alabang and Makati.

## 🛠️ Built With
* **HTML5** - Structured for SEO and accessibility.
* **CSS3** - Custom styling for a luxury real estate feel.
* **GitHub Pages** - Fast, reliable hosting.

## 📂 Project Structure
* `index.html` - The main landing page and property details.
* `style.css` - Custom styling including Southwind's signature branding.
* `assets/` - High-resolution property photos and site maps.
